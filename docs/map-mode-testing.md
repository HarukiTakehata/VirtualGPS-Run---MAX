# 地图模式切换

地图右上角点击“卫星”切换到卫星影像，点击“普通”返回普通地图。
应用会记住选择；切换只替换底图，不修改选点、路线、配速或定位投递。
两种模式使用独立瓦片缓存，保留原有最高显示缩放级别 22（原生瓦片到 18）。
首次加载卫星影像需要网络，影像清晰度与覆盖范围取决于图源。
